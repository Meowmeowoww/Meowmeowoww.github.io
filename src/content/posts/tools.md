清过一次工具，从四十多个砍到十来个。留下来的标准很粗暴：**打开就要能用，不教我做事**。

## 干活

| 用途 | 用的 | 为什么 |
| --- | --- | --- |
| 编辑器 | VS Code | 不是最好的，但是最不用换的 |
| 终端 | Windows Terminal + PowerShell | 原生，不折腾 |
| 版本控制 | Git + 命令行 | 图形界面反而记不住命令 |
| 记笔记 | Obsidian | 文件是本地 Markdown，不会跑 |

## 写东西

- **Markdown**：所有文字先落在 .md 里，再决定发哪儿。
- **一个静态站**：就是这个博客，没有后台，改完 push 就上线。

## 克制清单

这几样我**故意不用**：

- 番茄钟（打断比专注多）
- 任务管理软件（一张纸够了）
- 各种"第二大脑"（记下来不等于会用）

## 一点体会

工具的边际收益衰减得特别快。第十个工具带来的提升，可能还没有把第一个用熟来得大。

真正省时间的从来不是工具，是**不开始做那些本来就不该做的事**。
